Local-first / remote-escalation setup

1) Install Python deps
- pip install -r requirements-agentic-eval.txt

2) Download local semantic model (recommended for 8GB 4070 Laptop)
- Hugging Face model: Qwen/Qwen2.5-VL-3B-Instruct
- Download page: https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct
- Recommended: run bash download_local_models.sh
- Manual option: use huggingface-cli download Qwen/Qwen2.5-VL-3B-Instruct --local-dir <your_local_path>

3) Local artifact models
- This project now uses pyiqa metric names instead of manual checkpoint paths
- Default metrics: maniqa,musiq
- pyiqa will download needed weights automatically on first use

4) Recommended environment variables
- PLANNER_MODEL=Qwen/Qwen2.5-VL-3B-Instruct
- JUDGE_MODEL=Qwen/Qwen2.5-VL-3B-Instruct
- REPORT_MODEL=Qwen/Qwen2.5-VL-7B-Instruct
- REFLECTOR_MODEL=Qwen/Qwen2.5-VL-7B-Instruct
- LOCAL_SEMANTIC_ENABLED=true
- LOCAL_SEMANTIC_MODEL=/mnt/afs/zhengmingkai/zyr/THEMIS/models/Qwen2.5-VL-3B-Instruct
- SEMANTIC_LOCAL_FAST_MODEL=/mnt/afs/zhengmingkai/zyr/THEMIS/models/Qwen2.5-VL-3B-Instruct
- SEMANTIC_LOCAL_STRONGER_MODEL=/mnt/afs/zhengmingkai/zyr/THEMIS/models/Qwen2.5-VL-7B-Instruct
- LOCAL_SEMANTIC_DEVICE=cuda:3
- LOCAL_ARTIFACT_ENABLED=true
- LOCAL_ARTIFACT_METRICS=maniqa,musiq,niqe
- LOCAL_ARTIFACT_DEVICE=cuda:4
- SEMANTIC_ESCALATION_THRESHOLD=0.72
- ARTIFACT_CONFIDENCE_THRESHOLD=0.55

5) Current routing behavior
- planner / judge / report / reflector all use local Qwen-VL models
- semantic / structural / vqa experts use local Qwen-VL models
- artifact expert uses local IQA metrics only
- no Anthropic or other remote API is used in the main evaluation path

6) If you want fully manual downloads
- Qwen2.5-VL-3B-Instruct: https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct
- pyiqa docs: https://github.com/chaofengc/IQA-PyTorch
